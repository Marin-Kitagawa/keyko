# PRODUCT.md

## Product

Keyko is a Windows hotkey launcher: press a combo anywhere, make something happen.
It lives in the tray, arms global hotkeys, and executes actions — apps, folders,
URLs, shell commands, text snippets, key sequences, webhooks, scripts, and 38
built-in system actions.

## Users

One primary user: the owner of the machine (single-user desktop tool, no accounts,
no server). Power-user leanings: keyboard-first, automation-friendly, dislikes mouse
trips for repetitive tasks. Secondary mode: gaming (wants pause/exclusions so hotkeys
never fire mid-game).

## Jobs

- Arm and manage keyboard shortcuts for anything repeatable
- Fire those shortcuts instantly from any app, including elevated ones (optional)
- Keep snippets, expansions and clipboard text one combo away
- Stay out of the way: tray-resident, silent unless speaking, zero startup friction

## Principles

- The launcher disappears into the task; the tray icon is the whole chrome
- Every state is visible: armed/failed/paused, never a silent failure
- Feminine, cozy, pastel aesthetic is a product requirement, not decoration —
  it is why this launcher exists instead of PowerToys Run
- Keyboard-first, mouse-optional
